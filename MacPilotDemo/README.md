# MacPilotDemo

Native SwiftUI demo for MacPilot.

## Open in Xcode

Open `MacPilotDemo.xcodeproj` in Xcode 15 or newer, select the `MacPilotDemo` scheme, and press **Run**.

The demo uses sample data so it is safe to explore. It demonstrates:

- Local file search UI.
- File metadata inspector.
- Safe organization suggestions.
- Preview-style action confirmation.
- Undoable activity history.
- Local-only privacy messaging.

The current host has CommandLineTools but not Xcode, so native build/run cannot be verified until Xcode is installed.
